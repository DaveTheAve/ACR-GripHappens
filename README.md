# Grip Happens

**Tyre wear, sensible wet tarmac grip, damage, and consequences.**

Grip Happens is an offline/local-play tuning utility for **Assetto Corsa Rally**. It adds a tested recommended setup for tyre wear, wet-tarmac grip, meaningful mechanical damage, progressive gearbox consequences, suspension deformation, brake wear, and component failures—while still letting players tune individual systems.

## Quick start

1. Download and extract the complete release.
2. Run `Run Grip Happens.cmd`.
3. Choose **Recommended - Grip Happens**.
4. Close Assetto Corsa Rally and click **Review & apply**.
5. Put Steam in **Offline Mode**.
6. Use **Play ACR**.

Loading a setup only changes pending choices. Game files are changed only after you explicitly confirm **Apply**.

## Highlights

- Recommended gameplay setup with player-adjustable tuning
- Tyre wear and wet-tarmac grip controls
- Collision and engine damage consequences
- Progressive damaged gearbox behavior
- Damage-sensitive suspension toe/camber behavior
- Native brake wear and component failures
- Read-only damage snapshots and driving recordings
- Offline/local-play safeguards

## Removal and game updates

Use **Advanced → Restore original game files**, or `Emergency Restore.cmd` if the normal interface cannot open.

Grip Happens fingerprints the supported ACR files before any write. Unknown game updates or unrelated edits are refused instead of being forced. Do not copy old backups over a newer game build.

## Offline and privacy

Grip Happens is intended for **local, noncompetitive play only**. Put Steam into Offline Mode yourself.

The tool does not change firewall rules or Steam settings, and it does not upload anything automatically. The retained game-local safeguards are **not** a promise of complete network isolation or prevention of later cached-result submission.

## Windows

- Windows 11 x64
- Windows PowerShell 5.1 / .NET Framework WPF
- The release is currently unsigned. Do not disable Windows security or antivirus to force it to run.
